# PolarWriter

App AI locale indipendente. Include polarai_core.py: non devi installare un core separato.

Avvio: python app.py (Python 3 + Tkinter). Avvia un server OpenAI-compatible su localhost, connetti e seleziona il modello.

Questa prima versione offre un'interfaccia per inserire testo, richiedere una risposta ed esportarla. Non modifica file e non esegue task autonomi. Le funzionalità specialistiche avanzate sono ancora da sviluppare.
